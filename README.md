## Project List

Below are the main projects available in this repository:

### 1. Bluetooth Controlled Car
- **File:** [Blutooth_controlled_car](Blutooth_controlled_car)
- Description: Control a robotic car using Bluetooth communication.

### 2. Keypad Controlled Car
- **File:** [Keypard_controlled_car.c](Keypard_controlled_car.c)
- Description: Operate a car using keypad inputs.

### 3. WiFi Controlled Car
- **File:** [Wifi_controlled_car.c](Wifi_controlled_car.c)
- Description: Manage a robotic car through WiFi signals.

### 4. Camera Module Integration
- **File:** [camera_module_code.py](camera_module_code.py)
- Description: Code for interfacing and using a camera module in robotics projects.

### 5. Colour Tracking Robot
- **File:** [colour_tracking_robot.py](colour_tracking_robot.py)
- Description: A robot that tracks and follows objects based on color detection.

### 6. Ultrasonic Sensor with Raspberry Pi
- **File:** [ultrasonic_sensor_using_raspberrypi.py](ultrasonic_sensor_using_raspberrypi.py)
- Description: Integrate and program an ultrasonic sensor using a Raspberry Pi.
